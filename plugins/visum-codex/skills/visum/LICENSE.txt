## 1. Visum

Visum is software for creating, training, testing, coordinating and running local visual models. Visum Developer creates editable visual solutions and exports `.visum` files. Visum Player runs `.visum` files. The CLI, SDK and Visum Engine expose the same capabilities for applications and workflows.

The Visum AI Skill and official Visum agent-integration packages provide guided conversational access to documented Visum CLI and Engine workflows through supported host agents. They do not contain a separate visual model or grant a host agent authority beyond the permissions, confirmations and boundaries that apply to the underlying Visum operation.

The initial release supports Apple Silicon Macs running macOS 14 or later. Training, captures, model execution and project data remain local unless you deliberately export, publish or send something elsewhere.
